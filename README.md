# Overview

I built this AI agent to help startups reduce the time spent manually reviewing incoming emails in a company.

The agent classifies incoming emails into five categories:

- Investment
- Partnership
- Job Candidate
- Customer
- Other

For each category, the agent evaluates the email using category-specific signals to determine its credibility, collect supporting evidence, and assign an initial priority score.
It then compares the email against requirements and preferences defined by the human. The result of this comparison can increase or decrease the priority score.
Finally, emails are placed into a unified, priority-ranked inbox so that humans can review the most valuable opportunities first.

The goal is not to replace human decision-making, but to reduce the time spent reviewing low-value emails. The agent identifies which emails are most valuable and relevant, allowing humans to focus their attention on the highest-priority opportunities first.
